## Nginx

Nginx обслуживает HTTP-запросы, отдаёт статические файлы и передаёт запросы приложениям. Основной конфигурационный файл в Ubuntu — /etc/nginx/nginx.conf. Блок server задаёт виртуальный сервер, listen — порт, server_name — имена, location — обработку URI, root — каталог файлов, proxy_pass — адрес приложения. Перед применением изменений выполняют sudo nginx -t, затем sudo systemctl reload nginx.

## Прямой и обратный прокси

Прямой прокси действует со стороны клиента: например, предоставляет сотрудникам выход в Интернет с фильтрацией и контролем доступа. Обратный прокси принимает запросы к серверу и направляет их приложению: например, Nginx принимает HTTPS на 443 и передаёт запросы локальному приложению на 127.0.0.1:8000. Он может завершать TLS, распределять нагрузку и обслуживать статические файлы.

## TLS и сертификаты

При TLS-соединении стороны согласуют версию протокола и криптографические параметры, проверяют подлинность сервера и получают сеансовые ключи. Сертификат связывает имя сервера с открытым ключом. Клиент проверяет имя, срок действия и цепочку подписей до доверенного удостоверяющего центра. В типичном TLS 1.3 ключи согласуются с помощью эфемерного обмена; сертификат и цифровая подпись подтверждают сервер. Самоподписанный сертификат может обеспечивать шифрование, но браузер не доверяет его издателю автоматически. Предупреждение нельзя игнорировать без проверки происхождения сертификата.
